# Lab 2: Country Schools Data Analysis

## 1. Introduction

This project analyzes the Country Schools dataset using Python. The work includes basic data preprocessing, anomaly detection, and cluster analysis to identify unusual records and group areas with similar school-related characteristics.

## 2. Objectives

- Perform basic data preprocessing.
- Detect unusual observations using an anomaly detection algorithm.
- Group similar observations using a clustering algorithm.
- Interpret and explain the experimental results.

## 3. Dataset

The project uses the `Country Schools.csv` dataset, which contains school-related information for different areas. The dataset includes the total number of schools, installed schools, pending schools, installation percentage, and installed LDDs and TDDs.

## 4. Tools and Technologies

- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## 5. Methodology

### Data Preprocessing
Inspect the dataset, examine data types, handle missing values, and prepare numerical features for analysis.

### Anomaly Detection
Apply an appropriate anomaly detection algorithm to identify unusual observations and interpret the results.

### Cluster Analysis
Apply a clustering algorithm to group similar observations and interpret the characteristics of each cluster.
